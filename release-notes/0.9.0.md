# 0.9.0

- Arrange the Dashboard your way: drag section handles to move Maps and players, Battlegroup services, the overview cards, and the other dashboard sections up or down. Put your open maps first for easier viewing.
- Your layout is saved on this computer and reused across server dashboards and app restarts. Use **Reset layout** to restore the original order.
- Prefer a keyboard or touch controls? Use each section's up/down buttons, or focus its drag handle and press the up/down arrow keys. Attention notices remain above the movable sections.
- This release only changes dashboard presentation. Existing server actions, refreshes, spawning, and restart behavior are unchanged.

No SQL, database migration, Dune server update, or battlegroup restart is required. Install the desktop release through the in-app updater. The UI feature works with the existing 0.8.0 management service; updating that service is optional for version alignment, not required for this feature.
