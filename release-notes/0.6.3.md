# 0.6.3

- Fixed the dashboard occasionally remaining stuck on **Refreshing** after manually stopping or restarting a battlegroup.
- Refreshes now have a firm time limit. If the server is still changing state, the manager releases the controls, keeps the last successful snapshot, and lets you retry immediately.
- Late results from an expired refresh are ignored so older information cannot overwrite a newer successful check.
- SSH and Kubernetes status reads now have native safety deadlines and discard an unhealthy cached SSH session before the next attempt.
- Start, stop, and restart operations retain their longer completion windows, while the optional service-detail refresh can no longer hold the whole action open indefinitely.

No database action or Dune server restart is required. After installing the desktop update, use **Management Service → Install / Update** once to keep its synchronized version aligned with the app.
