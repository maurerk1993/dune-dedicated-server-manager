# Dependency security updates

- Updated the desktop framework, updater, SSH and PostgreSQL libraries, and frontend build tools to address available dependency security fixes.
- Kept the existing server controls, admin tools, schedules and Funcom-provided SSH-key workflow.
- Kept signed Windows installer, Linux AppImage and Debian-package updates; removed the unused legacy ZIP update extractor.

No SQL, database migration, or changes to Funcom's server files are required.
After installing this desktop release, use **Management Service → Install / Update** once to apply the PostgreSQL dependency fixes to the manager's own service. No Dune battlegroup restart is required.
