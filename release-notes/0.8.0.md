# 0.8.0

- Removed the manager's database backup task, manual backup action, automatic backup schedule, and backup-related cleanup controls. Backups are now left entirely to Funcom's provided script, so the manager cannot start or schedule one.
- Daily restart scheduling, in-game restart warnings, start/stop/restart controls, admin tools, server telemetry, and all other existing management features continue to work as before.
- Made admin command publishing safer by removing shared temporary RabbitMQ script files and serializing concurrent publishes. This prevents overlapping automated and manual commands from replacing or misdirecting each other's payloads.

No SQL or Dune database migration is required. After installing the desktop update, use **Management Service → Install / Update** once on each attached server. This replaces the older service and ensures any previously configured manager backup schedule can no longer run.
