# 0.3.17

This release moves the app's update and support links to the maintained fork.
The manager's server features are unchanged.

## Changed

- **Update checks now look at the fork's GitHub Releases.** Once this owned
  build is installed, future app updates can be delivered from
  `maurerk1993/dune-dedicated-server-manager` instead of the upstream project.
- **About and release-note links now point to the fork.** The in-app repository,
  issue tracker, and release notes links now open the maintained fork.

## Notes

- The first owned build must be installed manually. After that handoff install,
  the app can use the fork's signed updater artifacts for future updates.
- No server settings, saved server profiles, schedules, welcome packages, or
  management-service behavior changed.
