# 0.4.0

## Admin Progression

- Added **Specialization Level XP** under Admin > Progression.
- You can pick a player and set exact levels for Combat, Crafting, Exploration, Gathering, and Sabotage.
- For production safety, specialization edits only run while the selected player is offline. The player must fully relog before the new level appears in-game.

## Admin Inventory

- Added item tier selection for gradeable items in the Grant item command.
- Tier `0` keeps using the normal live grant path. Tiers `1` through `5` create Mk2-Mk6 items for one offline player.
- Custom-tier grants are blocked for online players and for items that do not support quality tiers. The player should relog after the item is granted.

## Notes

- No manual SQL migration is required.
- Update the bundled server service after installing this app version so the new Admin endpoints are available on your Dune machine.
