# 0.6.1

- Added a **Dismiss** control to the dashboard's **Needs attention** banner.
- Dismissals are remembered separately for each attached server, including after restarting the app.
- A dismissed banner automatically returns when its notices change, so new service, storage, memory, refresh, or restart conditions remain visible.
- Removed the game-server **Update** tab and the manual update actions from the desktop app.
- Removed **Auto Update** and its lead-time setting from **Automated tasks**. The management service no longer checks for or applies game-server updates, even if an older installation had automatic updates enabled.
- Game-server updates are now intentionally handled outside the app with Funcom's provided update script. Start, stop, restart, scheduled restart warnings, backups, app updates, and read-only build information are unchanged.

No database action is required; existing update settings and history remain dormant. After installing the desktop update, use **Management Service → Install / Update** once to deploy the update-free service and keep its version aligned with the app.
