# 0.7.0

- Added a dedicated **Maps** tab with an at-a-glance view of loaded map servers, readiness, players, and battlegroup uptime.
- Map status now shows Funcom's exact game-runtime phase—such as **Initializing** or **Post Landscape Physics**—instead of reducing every state to Online, Starting, or Offline.
- Each loaded map now includes practical diagnostics from the existing read-only refresh: map and sietch identity, partition and dimension, game and operator readiness, server simulation FPS, battlegroup role, map-server restart count, ports, and the reporting pod.
- Added **Start BattleGroup** and **Stop BattleGroup** controls to the Maps tab. They use the same verified-snapshot safety checks as the Dashboard and remain disabled when data is stale or the latest refresh failed.
- The Dashboard's compact **Maps and players** table now uses the same richer game phase while remaining a concise overview.

No database action or Dune server restart is required. After installing the desktop update, use **Management Service → Install / Update** once to keep its synchronized version aligned with the app.
