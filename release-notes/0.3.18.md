# 0.3.18

This release adds an optional auto-refresh control for the active server screen.

## Added

- **Auto-refresh for the open server.** The server detail screen now has an
  auto-refresh split button next to the manual Refresh button, so the visible
  server can keep itself current while you watch it.
- **Selectable refresh intervals.** Choose 15, 30, 60, or 180 seconds from the
  dropdown, then turn auto-refresh on or off from the main button.
- **Remembered preference.** The app remembers whether auto-refresh is enabled
  and which interval you chose after closing and reopening it.

## Notes

- Auto-refresh only targets the server page you are currently viewing.
- If a server refresh is already running, the app skips that tick and waits for
  the next interval instead of starting another refresh on top of it.
- No server settings, saved server profiles, schedules, welcome packages, or
  management-service behavior changed.
