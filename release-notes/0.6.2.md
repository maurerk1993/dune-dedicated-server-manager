# 0.6.2

- Fixed **Database utilities** incorrectly showing a problem after a fresh Dune server installation completed successfully.
- Finished one-time database setup pods are now treated as installation history instead of active services, so an old setup race cannot reduce the live ready count or trigger a false warning.
- Database Monitor and PgHero remain monitored normally, and a database setup pod that is still starting remains visible.

No database action or Dune server restart is required. After installing the desktop update, use **Management Service → Install / Update** once to keep its synchronized version aligned with the app.
