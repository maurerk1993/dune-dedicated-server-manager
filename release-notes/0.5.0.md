# 0.5.0

- Added an Admin item catalog updater with review-before-apply.
- You can now inspect added, changed, and removed item catalog entries before approving them.
- Approved catalog updates can be applied locally to the bundled server service and exported for inclusion in a future app release.
- Catalog validation now blocks suspicious or malformed updates before they can affect Grant Item searches or custom-tier item grants.

No manual database action is required. After updating, refresh the Dune server in the app and apply the bundled server service update.
