# 0.6.0

- Redesigned the dashboard into a clearer operator overview with live player counts, battlegroup service health, host RAM, CPU, Dune storage, and uptime.
- Added a plain-language service grid showing which Kubernetes pods are ready, whether containers have restarted, and per-service CPU/RAM when the host publishes those metrics.
- Added a focused **Needs attention** area for failed services, stale snapshots, refresh errors, high memory usage, and low disk space.
- Improved map status rows with friendly **Online**, **Starting**, and **Offline** labels.
- Upgraded the Servers screen with summary cards for players, services, RAM, disk, and last refresh time, plus a new **Refresh all** action.
- The app now keeps the last successful snapshot visible if a later refresh fails, while disabling server lifecycle actions until fresh data is available.

No database action or server configuration is required. After installing the desktop update, use **Management Service → Install / Update** once to keep the bundled service version aligned with the app.
